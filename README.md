# Youtube Score Capture (PWA)

유튜브 악보 영역을 지정하고, 악보가 바뀔 때마다 캡처한 뒤 PDF로 저장하는 웹앱입니다.

## 사용

1. 사이트 접속 (GitHub Pages 또는 `start.bat`)
2. 화면 공유 → 악보 영역 지정 → 시작
3. 썸네일 멀티 선택 후 삭제 가능
4. PDF 배열 1열 / 2열 선택 후 PDF 만들기
5. (모바일) 홈 화면에 추가하여 PWA로 사용

## 타브 키 조정 (`transpose.html`)

이 앱으로 만든 악보 PDF(또는 이미지)를 넣고 조정할 키(반음 수, 예: -6)를 입력하면 타브의 프렛 숫자와 줄 위치를 바꿉니다.

1. 메인 화면의 "타브 키 조정" → PDF 선택 → 조정 키 입력 → 인식 시작
2. 인식 결과 검수: 초록(정상) / 주황(확인 필요·표시 못 하는 음) / 보라(코드명) 박스를 확인하고, 틀린 곳은 클릭해 고침
3. 변환 미리보기 확인 후 "변환 PDF 저장"

- 기본은 4현(EADG)입니다. "5현 베이스"를 켜면 범위를 벗어난 음에 낮은 B줄을 추가해 사용합니다.
- 먼저 튜닝 없이 모든 음을 표시할 수 있는지 확인하고, 표시할 줄이 없는 음이 있을 때만 가장 낮은 줄을 최대 2반음까지 내리는 튜닝을 제안합니다. 고른 튜닝은 악보 왼쪽 아래에 "4번 줄 = D"처럼 표시됩니다.
- 옥타브를 옮겨 표시하지 않습니다. 튜닝을 하더라도 표시할 수 없으면 "튜닝을 하더라도 옥타브를 이동해야합니다. 조정 키 값을 줄여주세요."라고 알리고, 튜닝 제안에 "아니오"를 고르면 조정 키를 줄이라고 알립니다. 표시하지 못한 음이 있으면 PDF를 저장하지 않습니다.
- 오선보는 참고용으로 흐리게 표시하고, 코드명도 함께 이조합니다.
- 숫자·코드명 인식에 Tesseract.js(CDN)를 사용하므로 처음 한 번은 인터넷 연결이 필요합니다.
