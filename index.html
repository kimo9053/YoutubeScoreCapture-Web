Youtube 악보 캡처

유튜브 탭/창을 화면 공유한 뒤, 악보 영역만 지정하세요.

대기 저장: 0장
악보 영역: 미지정
마디 숫자: 미지정
선택: 0장

  1. 유튜브에서 악보 영상을 재생합니다.
  2. 화면 공유 → 유튜브 탭/창 선택 (모바일은 지원이 제한될 수 있음)
  3. 미리보기에서 악보만 드래그. 박스가 어긋나면 영역을 다시 지정
  4. 마디 숫자 영역은 숫자만 아주 작게. 주황 박스가 앱 영역이고, 음표 위 파란 칸은 유튜브입니다
  5. 마디 숫자 영역을 지정하면 마디 숫자 우선 캡처가 켜집니다. 숫자가 바뀔 때 한 장 저장합니다
  6. 시작 후 곡이 끝나 악보가 사라지면 자동으로 멈춥니다. 그다음 PDF 생성
  7. 중지 후 수동 캡처: 선택한 썸네일 뒤에 삽입. 썸네일 사이 +를 눌러 원하는 위치에 삽입
  8. 캡처 기능: PC Chrome/Edge 전용
  9. 갤럭시: 화면 공유 미지원 → PC에서 사용
  10. 아이폰·아이패드: 화면 공유 미지원 → PC에서 사용
화면 공유를 시작하면 미리보기가 표시됩니다.
